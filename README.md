# Magyar Group Finder

Magyar nyelvű csapatkereső addon World of Warcraft: Forever játékosoknak.

## Weboldal

A repository gyökerében található statikus oldal GitHub Pages-re készült.

Tervezett cím:

https://krumpleetv.github.io/MagyarGroupFinder/

## Hivatalos letöltés

https://www.curseforge.com/wow/addons/magyar-group-finder

## GitHub Pages bekapcsolása

A GitHubon nyisd meg: **Settings → Pages → Build and deployment → Deploy from a branch**, majd válaszd a **main** ágat és a **/(root)** mappát.

Az oldal tartalmaz:
- magyar elsődleges tartalmat és rövid angol összefoglalót;
- keresőbarát title/description/canonical metaadatokat;
- SoftwareApplication strukturált adatot;
- robots.txt fájlt OAI-SearchBot engedéllyel;
- sitemap.xml fájlt;
- CurseForge, Discord és Twitch hivatkozásokat.
